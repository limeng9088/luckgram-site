BotFather

ربات‌های Telegram خود را از راه @BotFather بسازید و مدیریت کنید.

برای یک حساب با @BotFather صحبت می‌کند و با هیچ‌کس دیگر: ربات تازه می‌سازد و توکن API آن را تحویل می‌دهد، نام، توضیحات، متن «درباره» و فرمان‌های ربات را تغییر می‌دهد، حریم خصوصی گروه را تغییر می‌دهد و ربات را حذف می‌کند. برای هر کار دیگری سه ابزار عمومی هست که یک خط می‌فرستند، دکمه‌ای را می‌زنند و گفتگو را می‌خوانند. فقط گفتگو با BotFather را می‌بیند، نه گفتگوهای دیگر حساب را.

چه کارهایی می‌تواند بکند

  • ساختن ربات و گرفتن توکن آن در یک فراخوانی
  • فهرست‌کردن ربات‌های حساب، گرفتن یا باطل‌کردن توکن
  • تنظیم نام، توضیحات، متن «درباره» و فهرست فرمان‌ها
  • تغییر حریم خصوصی گروه و اینکه ربات را بتوان به گروه‌ها اضافه کرد یا نه
  • حذف ربات، با دو بار دادن نام کاربری
  • انجام هر کار دیگری که BotFather ارائه می‌دهد، قدم‌به‌قدم: فرستادن، زدن دکمه، خواندن

از ابزار هوش مصنوعی‌تان بخواهید

  • رباتی به نام «فروشگاه من» با نام کاربری my_shop_bot بساز و توکنش را در یک فایل ذخیره کن.
  • فرمان‌های @my_shop_bot را تنظیم کن: start، order، help. برای هر کدام توضیح کوتاهی بنویس.
  • حساب کاری‌ام مالک کدام ربات‌هاست؟

روشن‌کردن

  1. در Luckgram Desktop این مسیر را باز کنید: Settings → Luckgram → Local MCP server.
  2. زیر Skills of each account حساب را پیدا کنید.
  3. BotFather را روشن کنید. Luckgram از شما تأیید می‌خواهد؛ برای این حساب فقط یک بار.

از خط فرمان

luckgram bots create my_shop_bot --name "My Shop" --out ~/my_shop_bot.token --account 7943234085
luckgram bots commands my_shop_bot 'start=Start' 'order=Track an order' 'help=How it works'
luckgram bots set my_shop_bot --description "Orders and delivery status" --privacy on
luckgram botfather send /setuserpic

با مهارت luckgram برای ایجنت‌ها.

خوب است بدانید

  • توکن ربات محرمانه است: هر کس آن را داشته باشد ربات را کنترل می‌کند. ابزارهایی که ربات می‌سازند، توکن می‌گیرند یا آن را باطل می‌کنند، توکن را به ابزار هوش مصنوعی شما برمی‌گردانند. این مهارت را فقط برای حساب‌هایی روشن کنید که این را می‌خواهید.
  • ابزارهای عمومی راه دورزدن نیستند: فرستادن /newbot، /deletebot یا /revoke رد می‌شود، و همین‌طور دکمه‌هایی که رباتی را حذف می‌کنند، توکنی را باطل می‌کنند یا رباتی را به کس دیگری منتقل می‌کنند. این کارها از راه ابزارهای خودشان انجام می‌شوند؛ انتقال را خودتان در برنامه انجام می‌دهید.
  • فقط با @BotFather واقعی صحبت می‌شود: با id آن در Telegram بررسی می‌شود، نه با نامش.
  • وقتی BotFather نمی‌پذیرد (“Sorry, this username is already taken”)، ابزار می‌ایستد و حرف آن را برمی‌گرداند.
