یک مهارت چطور روشن می‌شود

  1. سرور MCP را روشن کنیددر Luckgram Desktop: Settings → Luckgram → Local MCP server.
  2. مهارت‌ها را برای هر حساب روشن کنیددر همان صفحه، زیر نام هر حساب. مهارتی که حساب را تغییر می‌دهد یک بار از شما تأیید می‌خواهد.
  3. اتصال ابزار هوش مصنوعیClaude Code، Kiro، Codex، opencode یا هر کلاینت MCP. روش اتصال را ببینید.

مهارت luckgram برای ایجنت‌ها

یک ابزار خط فرمان و دستورالعمل‌هایی برای ایجنت‌هایی که مهارت بارگذاری می‌کنند، مثل Claude Code. یک فرمان همهٔ مهارت‌های بالا را پوشش می‌دهد؛ توکن دسترسی از ورودی استاندارد خوانده می‌شود، با مجوز فقط‌مالک ذخیره می‌شود و هرگز چاپ نمی‌شود.

  • luckgram accounts، chats list، messages get، messages send، friends add و بقیه
  • با سرور محلی و ابر کار می‌کند؛ Node 18 یا بالاتر، بدون وابستگی
  • قواعد ایجنت: از فهرست حساب‌ها شروع کن، محدودیت‌ها را رعایت کن، پیام را پیش از ارسال نشان بده

دانلود luckgram-skill.zip خواندن SKILL.md

نصب برای Claude Code:

curl -LO https://luckgram.cc/skills/luckgram/luckgram-skill.zip
unzip luckgram-skill.zip -d ~/.claude/skills/
node ~/.claude/skills/luckgram/bin/luckgram config --local --token-stdin

وقتی فرمان آخر منتظر ماند، توکن دسترسی را بچسبانید، سپس Enter و Ctrl-D را بزنید.
