دریافت Luckgram

دکمه‌ها آخرین نسخه را مستقیم دانلود می‌کنند. پیوندها پس از هر انتشار خودکار به‌روز می‌شوند.

Android

  • APK امضاشده برای گوشی‌های ۶۴ بیتی ARM (arm64-v8a)
  • Android 6.0 یا بالاتر
  • هر وقت پرسیده شد، به مرورگر یا مدیر فایل خود اجازهٔ نصب بدهید
دانلود APK
نسخه‌های دیگر

APK نسخهٔ x86_64 برای شبیه‌سازهای Android روی رایانه‌های x86 (Windows، Intel Mac). برای گوشی نیست.

دانلود APK نسخهٔ x86_64

iPhone و iPad

  • IPA امضانشده
  • پیش از نصب، آن را با Sideloadly، AltStore یا گواهی خودتان امضا کنید
  • iOS 15 یا بالاتر
دانلود IPAنصب روی iPhoneراهنمای نصب

فایل IPA را باید پیش از نصب خودتان امضا کنید. «نصب روی iPhone» یک نسخهٔ امضاشده است: این صفحه را در Safari روی همان دستگاه باز کنید و مراحل را دنبال کنید.

Windows (آزمایشی)

  • Windows 10 یا 11، ۶۴ بیتی
  • فقط برای کاربر شما نصب می‌شود؛ به دسترسی مدیر نیازی نیست
  • هنوز امضای کد ندارد: اگر SmartScreen هشدار داد، روی More info → Run anyway کلیک کنید
دانلود نصب‌کننده
نسخه‌های دیگر

نسخهٔ قابل‌حمل (ZIP): از حالت فشرده خارج کنید و Luckgram.exe را اجرا کنید؛ داده‌ها در همان پوشه می‌مانند.

دانلود نسخهٔ قابل‌حمل (ZIP)

اگر قبلاً یک نسخهٔ آزمایشی Luckgram را روی Android نصب کرده‌اید، ابتدا آن را حذف کنید: نسخه‌هایی که با کلید متفاوتی امضا شده‌اند نمی‌توانند یکدیگر را به‌روزرسانی کنند. Luckgram را فقط از همین صفحه یا مخزن‌های GitHub که این صفحه به آن‌ها پیوند داده دانلود کنید.
