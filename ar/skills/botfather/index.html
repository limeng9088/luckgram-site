BotFather

أنشئ بوتاتك على Telegram وأدِرها عبر @BotFather.

تتحدث مع @BotFather لحساب واحد، ولا مع أحد سواه: تنشئ بوتًا جديدًا وتعيد رمز API الخاص به، وتغيّر اسم البوت ووصفه ونص نبذته وأوامره، وتبدّل خصوصية المجموعات، وتحذف بوتًا. ولكل ما عدا ذلك ثلاث أدوات عامة ترسل سطرًا وتضغط زرًا وتقرأ المحادثة. لا ترى إلا المحادثة مع BotFather، لا محادثات الحساب الأخرى.

ما تستطيع فعله

  • إنشاء بوت والحصول على رمزه في استدعاء واحد
  • عرض بوتات الحساب، والحصول على رمز أو إبطاله
  • تعيين الاسم والوصف ونص النبذة وقائمة الأوامر
  • تبديل خصوصية المجموعات والسماح بإضافة البوت إلى المجموعات أو منعه
  • حذف بوت، مع كتابة اسم المستخدم مرتين
  • تنفيذ أي شيء آخر يتيحه BotFather، خطوة بخطوة: أرسل، اضغط، اقرأ

اسأل أداة الذكاء الاصطناعي

  • أنشئ بوتًا اسمه «متجري» باسم المستخدم my_shop_bot واحفظ رمزه في ملف.
  • عيّن أوامر @my_shop_bot: start وorder وhelp. واكتب وصفًا قصيرًا لكل منها.
  • ما البوتات التي يملكها حساب العمل؟

فعّلها

  1. في Luckgram Desktop افتح Settings → Luckgram → Local MCP server.
  2. تحت Skills of each account، اعثر على الحساب.
  3. فعّل BotFather. يطلب منك Luckgram التأكيد، مرة واحدة لهذا الحساب.

من سطر الأوامر

luckgram bots create my_shop_bot --name "My Shop" --out ~/my_shop_bot.token --account 7943234085
luckgram bots commands my_shop_bot 'start=Start' 'order=Track an order' 'help=How it works'
luckgram bots set my_shop_bot --description "Orders and delivery status" --privacy on
luckgram botfather send /setuserpic

مع مهارة luckgram للوكلاء.

يحسن أن تعرف

  • رمز البوت سرّ: من يملكه يتحكم في البوت. الأدوات التي تنشئ بوتًا أو تحصل على رمز أو تبطله تعيد الرمز إلى أداة الذكاء الاصطناعي. فعّل هذه المهارة فقط للحسابات التي تريد فيها ذلك.
  • الأدوات العامة ليست طريقًا للالتفاف: يُرفض إرسال /newbot أو /deletebot أو /revoke، وكذلك الأزرار التي تحذف بوتًا أو تبطل رمزًا أو تنقل بوتًا إلى شخص آخر. هذه تمر عبر أدواتها الخاصة؛ أما النقل فتجريه أنت في التطبيق.
  • لا يجري التحدث إلا مع @BotFather الحقيقي: يُتحقَّق منه بمعرّفه في Telegram، لا باسمه.
  • حين يرفض BotFather (“Sorry, this username is already taken”)، تتوقف الأداة وتعيد كلماته.
