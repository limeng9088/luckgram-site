البروكسي

اعرض البروكسي الذي يتصل Luckgram عبره وأضف غيره وبدّل بينها.

يعرض البروكسيات المحفوظة في Luckgram وأيّها قيد الاستخدام، ويضيف بروكسي SOCKS5 أو HTTP أو MTProto من عنوانه أو من رابط بروكسي، ويبدّل إلى بروكسي محفوظ أو إلى اتصال مباشر أو إلى بروكسي النظام، ويحذف بروكسي محفوظاً. البروكسي إعداد للتطبيق كله: كل الحسابات تتصل عبره.

ما تستطيع فعله

  • عرض البروكسيات المحفوظة وأيّها قيد الاستخدام
  • إضافة بروكسي SOCKS5 أو HTTP أو MTProto بالعنوان أو بالرابط
  • التبديل إلى بروكسي محفوظ أو إلى اتصال مباشر أو إلى بروكسي النظام
  • حذف بروكسي محفوظ
  • لا تُعاد كلمات المرور ولا أسرار MTProto أبداً

اسأل أداة الذكاء الاصطناعي

  • أيّ بروكسي يستخدمه Luckgram الآن؟
  • أضف بروكسي SOCKS5 بالعنوان 10.0.0.2:1080 وبدّل إليه.
  • أعد Luckgram إلى الاتصال المباشر.

فعّلها

  1. في Luckgram Desktop افتح Settings → Luckgram → Local MCP server.
  2. تحت Skills of each account، اعثر على الحساب.
  3. فعّل Proxy. يطلب منك Luckgram التأكيد، مرة واحدة لهذا الحساب.

الأدوات

الأداةما تفعلهالوسائطالقيم المُعادةالحد لكل حساب
list_proxiesالبروكسيات المحفوظة وأيّها قيد الاستخدام.accountmode (direct، proxy أو system)، proxies: index، type، host، port، user، has_password، selected–
add_proxyيحفظ بروكسي ويبدّل إليه ما لم يُطلب غير ذلك.account، ومعه إمّا link أو type، host، port مع user، password، secret اختيارياً؛ useadded، index، used والقائمة20 في الساعة، 60 في اليوم
use_proxyيبدّل إلى بروكسي محفوظ أو إلى اتصال مباشر أو إلى بروكسي النظام.account، ومعه إمّا index أو modemode والقائمة20 في الساعة، 60 في اليوم
remove_proxyيحذف بروكسي محفوظاً.account، indexremoved والقائمة20 في الساعة، 60 في اليوم

account هو id من list_accounts؛ ومن دونه يُستخدم الحساب النشط. على السحابة تأخذ كل أداة device أيضًا.

من سطر الأوامر

luckgram proxy list
luckgram proxy add --type socks5 --host 10.0.0.2 --port 1080
luckgram proxy use 2
luckgram proxy use direct

مع مهارة luckgram للوكلاء.

يحسن أن تعرف

  • لا يُختبر البروكسي قبل أن يبدّل Luckgram إليه. إذا لم يعمل ينقطع اتصال Luckgram ومعه Cloud MCP إلى أن تغيّر البروكسي من داخل التطبيق.
  • تُفعَّل هذه المهارة لكل حساب على حدة مثل غيرها، لكن البروكسي الذي تغيّره مشترك بين كل الحسابات.
  • حذف البروكسي المستخدَم يبدّل إلى اتصال مباشر.
