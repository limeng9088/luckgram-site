كيف تُفعَّل المهارة

  1. فعّل خادم MCPفي Luckgram Desktop: Settings → Luckgram → Local MCP server.
  2. فعّل المهارات لكل حسابفي الصفحة نفسها، تحت اسم كل حساب. المهارة التي تغيّر الحساب تطلب منك التأكيد مرة واحدة.
  3. اربط أداة الذكاء الاصطناعيClaude Code أو Kiro أو Codex أو opencode أو أي عميل MCP. اعرف الطريقة.

مهارة luckgram للوكلاء

أداة سطر أوامر وتعليمات للوكلاء الذين يحمّلون المهارات، مثل Claude Code. أمر واحد يغطي كل المهارات أعلاه؛ يُقرأ رمز الوصول من الدخل القياسي، ويُحفظ بصلاحيات للمالك فقط، ولا يُطبع أبدًا.

  • luckgram accounts وchats list وmessages get وmessages send وfriends add وبقية الأوامر
  • تعمل مع الخادم المحلي والسحابة؛ Node 18 أو أحدث، دون اعتماديات
  • قواعد للوكيل: ابدأ من قائمة الحسابات، التزم بالحدود، اعرض الرسالة قبل إرسالها

تنزيل luckgram-skill.zip اقرأ SKILL.md

التثبيت لـ Claude Code:

curl -LO https://luckgram.cc/skills/luckgram/luckgram-skill.zip
unzip luckgram-skill.zip -d ~/.claude/skills/
node ~/.claude/skills/luckgram/bin/luckgram config --local --token-stdin

الصق رمز الوصول حين ينتظر الأمر الأخير، ثم اضغط Enter وCtrl-D.
