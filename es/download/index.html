Descarga Luckgram

Los botones descargan directamente la versión más reciente. Los enlaces se actualizan solos después de cada lanzamiento.

Android

  • APK firmado para teléfonos ARM de 64 bits (arm64-v8a)
  • Android 6.0 o posterior
  • Cuando se te pida, permite las instalaciones desde tu navegador o gestor de archivos
Descargar APK
Otras versiones

APK x86_64 para emuladores de Android en computadoras x86 (Windows, Mac con Intel). No es para teléfonos.

Descargar APK x86_64

iPhone y iPad

  • IPA sin firmar
  • Fírmalo con Sideloadly, AltStore o tu propio certificado antes de instalarlo
  • iOS 15 o posterior
Descargar IPAInstalar en iPhoneGuía de instalación

Tienes que firmar el IPA tú mismo antes de poder instalarlo. “Instalar en iPhone” es una versión firmada: abre esta página en Safari desde el dispositivo y sigue los pasos.

Windows (beta)

  • Windows 10 u 11, de 64 bits
  • Se instala solo para tu usuario, sin permisos de administrador
  • Aún sin firma de código: si SmartScreen muestra una advertencia, haz clic en Más información → Ejecutar de todas formas
Descargar instalador
Otras versiones

ZIP portátil: descomprímelo y ejecuta Luckgram.exe; los datos se quedan en esa carpeta.

Descargar ZIP portátil

Si antes instalaste una versión de prueba de Luckgram en Android, desinstálala primero: las versiones firmadas con claves distintas no pueden actualizarse entre sí. Descarga Luckgram solo desde esta página o desde los repositorios de GitHub a los que enlaza.
