隐私政策

最后更新：2026 年 11 月 4 日

本政策说明你使用 Luckgram iOS 和 Android 应用以及 luckgram.cc 网站时，你的信息会如何处理。Luckgram 是基于开源 Telegram 应用开发的独立应用。

你的 Telegram 数据

Luckgram 是 Telegram 网络的客户端。你登录、发消息、打电话或同步联系人时，应用直接与 Telegram 的服务器交换这些数据。这些数据由 Telegram 依据 Telegram 隐私政策处理，而不是由 Luckgram 处理。

Luckgram 没有为你的消息、通话、联系人或媒体设立自己的服务器，也不会收到它们的副本。例外是下一节列出的 Luckgram 功能，只有在你使用这些功能时才会发送数据。

使用 Luckgram 服务器的功能

部分 Luckgram 功能运行在 Luckgram 运营的服务器上，服务器位于新加坡的 Amazon Web Services。每个功能都可以在「设置 → Luckgram 功能」里关闭。

  • 设备登记。首次使用时，应用会登记一个匿名设备令牌，以及系统平台、应用版本和语言。我们只保存令牌的哈希值。180 天没有连接的设备会被删除。
  • 账号关联。需要账号的功能（AI 额度、附近的人、广场、Luckgram Pro）会通过 Luckgram 机器人，把你的设备和 Telegram 用户 ID 关联起来。我们只保存数字用户 ID，不保存手机号。你可以在「设置 → Luckgram 功能 → 账号」里解除关联。
  • AI 功能（助手、总结、写作、回复建议、图片、帖子、语音转文字和通话文字稿）。你选择处理的文字、音频或提示词会经由我们的服务器发给 OpenAI 生成结果，再返回给你。我们不保存、也不记录这些内容；只为执行额度保留用量记录（功能、用量、时间）90 天。生成的图片保留 24 小时，供你下载。OpenAI 依据其自身条款处理这些内容。AI 对话历史只保存在你的设备上。
  • 附近的人（仅在你打开「在附近可见」时）。应用会先在设备上把你的位置粗化到约 1 公里的网格再发送，精确位置不会离开设备。你的名片（显示名、简介、可选头像和公开用户名）和粗化后的位置在 24 小时后自动删除；你关闭可见、退出登录或解除关联时立即删除。其他用户只能看到距离范围，看不到你的坐标。
  • 广场。帖子、评论和点赞对所有 Luckgram 用户公开。上传前，应用会压缩图片并去掉包括 GPS 在内的元数据；视频会重新编码并去掉元数据。你可以删除任何一条自己的帖子或评论，也可以在「设置 → Luckgram 功能 → 账号」里一键删除全部广场数据。已删除帖子的图片和视频在 24 小时内删除，被删除数据的所有副本在 30 天内清除。被举报的内容可能会被审核和隐藏。
  • 广场推荐。为了在广场里给你推荐可能感兴趣的帖子，Luckgram 会记录你在广场里的浏览和互动：看到了哪些帖子、停留多久、点开、点赞、评论、分享、举报和「不感兴趣」。这些记录只和一个不透明的设备或用户标识关联，不包含帖子文字或你的聊天内容，只用于广场的推荐和排序（包括改进推荐效果），不会用于广场以外的地方，也不会和其他 App 或网站的数据关联（不做跨 App 追踪），90 天后自动删除。
  • Luckgram Pro。使用 Telegram Stars 付款，由 Telegram 处理。我们只保存你的 Telegram 用户 ID 和会员有效期，不保存付款信息。
  • 配置、公告和更新。应用会从我们的服务器下载功能配置、应用内公告和版本信息。这些请求只带设备令牌和应用版本。

服务器日志只记录请求类型、结果和耗时等技术信息，不记录消息、帖子或 AI 内容，保留 30 天。我们不出售你的数据，也不将其用于广告。

存储在你设备上的数据

和其他 Telegram 应用一样，Luckgram 会在你的设备上缓存聊天和媒体，让应用运行更快、离线也能查看。你可以在应用的存储设置里清除缓存，卸载应用也会将其删除。

统计和广告

Luckgram 没有在应用中加入统计、广告或追踪 SDK。部分公开频道里由 Telegram 展示的赞助消息来自 Telegram，并遵循 Telegram 的政策。

Apple 和 Google 的服务

应用会使用操作系统或 Telegram 代码中内置的服务：iOS 上的推送通知通过 Apple 推送通知服务送达，Android 上通过 Firebase Cloud Messaging 送达；Android 上的地图和定位功能可能使用 Google Play 服务。这些服务商依据各自的隐私政策处理数据。

下载

应用安装包从 dl.luckgram.cc 下载，文件存放在 Amazon Web Services，经由 Cloudflare 分发。分发过程中 Cloudflare 可能会处理 IP 地址等技术数据。我们自己不记录下载日志。

我们的网站

luckgram.cc 和 wiki.luckgram.cc 是托管在 GitHub Pages、经由 Cloudflare 提供访问的静态网站。这些服务商可能会处理 IP 地址、浏览器类型等技术数据，用于提供和保护网站。网站本身不使用 Cookie，也没有自己的统计。

电子邮件

如果你给 luckgram.cc 的邮箱写信，我们会收到你的邮箱地址和邮件内容，只用于回复你。发往这些地址的邮件经由 Cloudflare Email Routing 转发。

儿童

Luckgram 不面向未达到其所在国家 Telegram 最低使用年龄的儿童。

政策变更

我们可能会更新本政策，页面顶部的日期是最后一次修改的时间。
