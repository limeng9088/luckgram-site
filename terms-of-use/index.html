最后更新：2026 年 10 月 24 日

本条款适用于你对 Luckgram 应用和 luckgram.cc 网站的使用。使用 Luckgram 即表示你同意本条款。

Luckgram 是什么

Luckgram 是基于开源 Telegram 应用开发的独立应用，并非由 Telegram 制作，与 Telegram 没有关联，也未获其认可。Telegram 是 Telegram FZ-LLC 的商标。

Telegram 的条款依然适用

Luckgram 将你连接到 Telegram 网络。你的 Telegram 账号及你用它进行的一切活动，均受 Telegram 服务条款约束。Telegram 可能依据自身规则限制或封禁账号，Luckgram 无法撤销这些决定。

合理使用

不得使用 Luckgram 发送垃圾信息、诈骗或骚扰他人、传播违法内容，或违反你所在地的法律。

Telegram Premium 和 Stars

Telegram Premium、Telegram Stars 及其他 Telegram 付费服务由 Telegram 销售和管理。Luckgram 免费，不出售这些服务。

开源许可

Luckgram 基于 Telegram 应用开发，Telegram 以 GNU 通用公共许可证（GPL）发布这些应用。Luckgram 的完整源代码在 GitHub 上公开：iOS 和 Android。

安装包

Luckgram 通过 GitHub Releases 发布。请只从 luckgram.cc 上的链接或上面的 GitHub 仓库下载。iOS 版如何签名和安装由你自行负责。

免责声明

Luckgram 按“现状”提供，不作任何形式的保证。标注为开发中的功能可能会变更，也可能不会上线。在法律允许的范围内，Luckgram 不对你使用应用或网站造成的任何损失承担责任。
