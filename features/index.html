用你的语言阅读消息

已上线

扫码、粘贴链接或导入订阅就能加代理，登录前就能用

连不上 Telegram？登录流程的每一页右上角都有代理按钮，收验证码之前就能添加 SOCKS5 或 MTProto 代理。新增两种加代理的方式：一是扫码或粘贴链接，扫一下代理二维码，或者粘贴 tg://、t.me 或 socks5:// 链接，代理就加进列表，不用逐项填服务器和端口；二是导入订阅，粘贴 Clash / mihomo 订阅网址，里面的 SOCKS5 节点一次全部导入，之后可以一键刷新，订阅删了，它导入的代理也一起删。代理列表里，每个 SOCKS5 代理下面会显示它的出口国家和 IP，最上面的“直连”一行显示不用代理时你自己的出口。登录后，在聊天列表右上角「⋮」菜单的最上面就能找到“代理配置”。
