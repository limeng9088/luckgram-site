代理

查看、添加和切换 Luckgram 使用的代理。

列出 Luckgram 里保存的代理和当前使用的是哪一个，按地址或代理链接添加 SOCKS5、HTTP、MTProto 代理，切换到某个已保存的代理、直连或系统代理，删除已保存的代理。代理是整个应用的设置：所有账号都走它。

能做什么

  • 查看已保存的代理和当前使用的是哪一个
  • 按地址或链接添加 SOCKS5、HTTP、MTProto 代理
  • 切换到已保存的代理、直连或系统代理
  • 删除已保存的代理
  • 不会返回代理密码和 MTProto 密钥

对 AI 工具这样说

  • Luckgram 现在用的是哪个代理？
  • 添加 SOCKS5 代理 10.0.0.2:1080 并切换过去。
  • 把 Luckgram 切回直连。

怎么打开

  1. 在 Luckgram 桌面版里打开 设置 → Luckgram 功能 → 本机 MCP 接口。
  2. 在每个账号的 Skill 下面找到那个账号。
  3. 打开代理。 Luckgram 会让你确认一次，每个账号只确认一次。

工具

工具作用参数返回每账号上限
list_proxies已保存的代理和当前使用的是哪一个。accountmode（direct、proxy 或 system）、proxies：index、type、host、port、user、has_password、selected–
add_proxy保存一个代理，默认同时切换过去。account，以及 link，或者 type、host、port 加可选的 user、password、secret；useadded、index、used 和代理列表每小时 20 次，每天 60 次
use_proxy切换到已保存的代理、直连或系统代理。account，以及 index 或 modemode 和代理列表每小时 20 次，每天 60 次
remove_proxy删除一个已保存的代理。account、indexremoved 和代理列表每小时 20 次，每天 60 次

account 是 list_accounts 返回的 id，不填就是当前账号。在云端，每个工具还可以带 device。

命令行

luckgram proxy list
luckgram proxy add --type socks5 --host 10.0.0.2 --port 1080
luckgram proxy use 2
luckgram proxy use direct

需要安装给 Agent 用的 luckgram Skill。

注意事项

  • 切换前不会测试代理能不能用。代理不通时 Luckgram 会掉线，云端 MCP 也跟着断开，需要你在应用里把代理改回来。
  • 这个 Skill 和其他 Skill 一样按账号开启，但它修改的代理是所有账号共用的。
  • 删除正在使用的代理后会改为直连。
