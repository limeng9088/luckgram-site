功能 网页版 MCP Skill 帮助 常见问题

Skill

AI 工具可以对你的每个账号做什么。

Skill 是 Luckgram MCP 接口里的一组工具。Skill 在桌面版里按账号单独开启（设置 → Luckgram 功能 → 本机 MCP 接口），默认全部关闭。AI 工具调用没有开启的 Skill 会被拒绝，并被告知需要哪个账号的哪个 Skill。

Skill 工具都有可选参数 account（list_accounts 返回的 id）。指定后直接对那个账号操作，不用切换界面；不填就是当前账号。

账号 accounts

查看桌面版里已登录的账号，切换当前账号。MCP 接口开启后始终可用。 始终开启

工具作用参数每账号上限
list_accounts列出已登录账号：id、昵称、用户名、手机号、未读数、哪个是当前账号。无–
get_active_account主窗口当前显示的账号。无–
switch_account切换到另一个账号，和点侧栏里的账号一样。id、username、phone、index 四选一–

好友 friends

查看某个账号的好友，按用户名或手机号查找用户。 只读

工具作用参数每账号上限
list_friends账号的好友列表和总数。account、query、limit、offset–
find_user以该账号的身份按用户名或手机号查找用户。account，username、phone 二选一每小时 30 次，每天 100 次

管理好友 friends_manage

加好友、删好友。不会发送任何消息。 会改动账号 · 开启时确认一次

工具作用参数每账号上限
add_friend把用户加为该账号的好友。account，user_id、username、phone 三选一，可选 first_name、last_name每小时 5 次，每天 20 次
remove_friend把用户从该账号的好友里删除，聊天记录保留。account，user_id、username 二选一每小时 20 次，每天 50 次

会话 chats

查看某个账号的会话列表和未读数，不含消息内容。 只读

工具作用参数每账号上限
list_chats按会话列表的顺序返回：类型、名称、未读数、是否静音、是否置顶、最后一条消息的时间。account、unread_only、limit、offset–

读消息 messages

读取会话里的消息内容，不会把会话标记为已读。 只读

工具作用参数每账号上限
get_messages会话的最近消息，从新到旧：id、时间、发送者、文字、附件类型。account、chat、limit、before_id–

发消息 messages_send

以该账号的身份发送文字消息，一次只发给一个会话，没有群发工具。 会改动账号 · 开启时确认一次

工具作用参数每账号上限
send_message向一个会话发送一条纯文本消息，走应用自己的发送流程。account、chat、text，可选 reply_to每小时 30 次，每天 200 次

管理会话 chats_manage

把会话标记为已读。 会改动账号 · 开启时确认一次

工具作用参数每账号上限
mark_chat_read把一个会话里的消息全部标记为已读。account、chat每小时 60 次，每天 500 次

群组和频道 groups

加入公开的群组或频道，退出群组或频道。 会改动账号 · 开启时确认一次

工具作用参数每账号上限
join_chat加入一个公开的群组或频道。account、chat每小时 5 次，每天 20 次
leave_chat退出一个超级群或频道。自己创建的不能用它退出。account、chat每小时 10 次，每天 30 次

资料 profile

修改账号的昵称和简介。 会改动账号 · 开启时确认一次

工具作用参数每账号上限
update_profile修改昵称和（或）简介，没填的保持不变。account，first_name、last_name、bio 至少一个每小时 5 次，每天 10 次

给 Agent 用的 Skill 文件

支持 Skill 的 Agent（Claude Code 等）有了使用说明会用得更好：先调用 list_accounts、遵守频率上限、汇报改动了什么。下载 SKILL.md，放到 Agent 加载 Skill 的目录里。以 Claude Code 为例：

mkdir -p ~/.claude/skills/luckgram
curl -o ~/.claude/skills/luckgram/SKILL.md https://luckgram.cc/skills/luckgram/SKILL.md

频率上限按账号、按工具计数，重启后仍然有效。它用来避免账号被 Telegram 限制，不能关闭。
