Skill 市场

一个 Skill，就是你的 AI 工具可以对你某个 Telegram 账号做的一件事。挑你需要的，按账号逐个打开。

Skill 是怎么打开的

  1. 打开 MCP 接口在 Luckgram 桌面版里：设置 → Luckgram 功能 → 本机 MCP 接口。
  2. 按账号打开 Skill在同一页里，每个账号名下各有一组开关。会改动账号的 Skill 要你确认一次。
  3. 连接 AI 工具Claude Code、Kiro、Codex、opencode 或任何 MCP 客户端。查看接法。

给 Agent 用的 luckgram Skill

一个命令行工具，加上给 Agent 的使用说明，适用于 Claude Code 等会加载 Skill 的 Agent。一个命令覆盖上面所有 Skill；访问令牌从标准输入读取，以仅本人可读的权限保存，不会被输出。

  • luckgram accounts、chats list、messages get、messages send、friends add 等命令
  • 本机接口和云端都能用；需要 Node 18 或更高版本，没有其他依赖
  • 给 Agent 的规则：先看账号列表、遵守频率上限、发送前先给你看

下载 luckgram-skill.zip 查看 SKILL.md

为 Claude Code 安装：

curl -LO https://luckgram.cc/skills/luckgram/luckgram-skill.zip
unzip luckgram-skill.zip -d ~/.claude/skills/
node ~/.claude/skills/luckgram/bin/luckgram config --local --token-stdin

最后一条命令等待输入时粘贴访问令牌，然后按回车和 Ctrl-D。
