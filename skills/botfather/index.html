BotFather 机器人管理

通过 @BotFather 创建和管理你的 Telegram 机器人。

以某个账号的身份和 @BotFather 对话，而且只和它对话：创建新机器人并取回 API 令牌，修改机器人的名称、说明、简介和命令，切换群组隐私模式，删除机器人。其余的事情有三个通用工具：发一句话、点一个按钮、读这个会话。它只能看到和 BotFather 的会话，看不到账号的其他会话。

能做什么

  • 一次调用创建机器人并拿到令牌
  • 列出账号的机器人，取令牌或重置令牌
  • 设置名称、说明、简介和命令列表
  • 切换群组隐私模式、是否允许被拉进群
  • 删除机器人，需要把用户名写两遍
  • BotFather 的其他功能也能一步一步完成：发送、点按钮、读取

对 AI 工具这样说

  • 创建一个叫“我的小店”的机器人，用户名 my_shop_bot，把令牌保存到文件里。
  • 给 @my_shop_bot 设置命令：start、order、help，每个配一句简短说明。
  • 我的工作号名下有哪些机器人？

怎么打开

  1. 在 Luckgram 桌面版里打开 设置 → Luckgram 功能 → 本机 MCP 接口。
  2. 在每个账号的 Skill 下面找到那个账号。
  3. 打开BotFather 机器人管理。 Luckgram 会让你确认一次，每个账号只确认一次。

account 是 list_accounts 返回的 id，不填就是当前账号。在云端，每个工具还可以带 device。

命令行

luckgram bots create my_shop_bot --name "My Shop" --out ~/my_shop_bot.token --account 7943234085
luckgram bots commands my_shop_bot 'start=Start' 'order=Track an order' 'help=How it works'
luckgram bots set my_shop_bot --description "Orders and delivery status" --privacy on
luckgram botfather send /setuserpic

需要安装给 Agent 用的 luckgram Skill。

注意事项

  • 机器人令牌是密钥，拿到它的人就能控制机器人。创建机器人、取令牌、重置令牌这三个工具会把令牌返回给你的 AI 工具。只给你愿意这样做的账号开启。
  • 通用工具不是后门：发送 /newbot、/deletebot、/revoke 会被拒绝，删除机器人、重置令牌、把机器人转让给别人的按钮也会被拒绝。这些操作只能走各自的工具；转让只能由你在应用里完成。
  • 只和真正的 @BotFather 对话：按它的 Telegram id 核对，而不是按名字。
  • BotFather 拒绝时（比如“这个用户名已被占用”），工具会立即停下并原样返回它的话。
