管理好友

加好友、删好友。不会发送任何消息。

把用户加到某个账号的好友里，或把好友删除。不会给对方发消息。因为它会改动账号，开启时需要你确认一次，每次调用都受频率上限约束。

能做什么

  • 按用户 id、用户名或手机号加好友，可指定保存的备注名
  • 删除好友，聊天记录保留
  • 对方已经是好友或本来就不是好友时如实返回，而不是报错

对 AI 工具这样说

  • 把 @some_user 加到我工作号的好友里，备注“李伟”。
  • 把 @old_contact 从我客服号的好友里删掉。

怎么打开

  1. 在 Luckgram 桌面版里打开 设置 → Luckgram 功能 → 本机 MCP 接口。
  2. 在每个账号的 Skill 下面找到那个账号。
  3. 打开管理好友。 Luckgram 会让你确认一次，每个账号只确认一次。

工具

工具作用参数返回每账号上限
add_friend把用户加为该账号的好友。account，user_id、username、phone 三选一；可选 first_name、last_nameadded、already_friend、user每小时 5 次，每天 20 次
remove_friend把用户从该账号的好友里删除。account，user_id、username 二选一removed、was_friend、user每小时 20 次，每天 50 次

account 是 list_accounts 返回的 id，不填就是当前账号。在云端，每个工具还可以带 device。

命令行

luckgram friends add @some_user --first "Li" --last "Wei" --account 7943234085
luckgram friends remove @old_contact --account 7943234085

需要安装给 Agent 用的 luckgram Skill。

注意事项

  • 能看好友不等于能改好友：这个 Skill 有自己单独的开关。
  • 超过上限的调用会被拒绝，并说明还要等多少秒。上限不能关闭。
