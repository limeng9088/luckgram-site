# luckgram.cc

Static website for Luckgram, served by GitHub Pages behind Cloudflare.

Pages are generated by `scripts/build.py`; edit the content there, then run
`python3 scripts/build.py` and commit the output.

## Feature list

`data/features.json` is the single list of Luckgram features (id, Chinese and English
name, one-line title, description, group, status, Help Center path). The features page
and the feature cards on the home page are generated from it, and wiki.luckgram.cc
copies the same file (`scripts/sync-features.py` in luckgram-wiki) for its feature
catalog and the status line on each feature page.

When a feature ships or changes, edit `data/features.json`, run
`python3 scripts/build.py`, and then sync the wiki.
