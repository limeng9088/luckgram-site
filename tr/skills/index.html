Bir beceri nasıl açılır

  1. MCP sunucusunu açLuckgram Desktop'ta: Settings → Luckgram → Local MCP server.
  2. Becerileri hesap bazında açAynı sayfada, her hesabın adının altında. Hesapta değişiklik yapan bir beceri senden bir kez onay ister.
  3. Yapay zekâ aracını bağlaClaude Code, Kiro, Codex, opencode veya herhangi bir MCP istemcisi. Nasıl yapıldığını gör.

Ajanlar için luckgram becerisi

Claude Code gibi beceri yükleyen ajanlar için bir komut satırı aracı ve talimatlar. Tek komut yukarıdaki tüm becerileri kapsar; erişim belirteci standart girdiden okunur, yalnızca sahibine açık izinlerle saklanır ve asla ekrana yazdırılmaz.

  • luckgram accounts, chats list, messages get, messages send, friends add ve diğerleri
  • Yerel sunucuyla ve bulutla çalışır; Node 18 veya üzeri, bağımlılık yok
  • Ajan için kurallar: hesap listesinden başlamak, sınırlara uymak, mesajı göndermeden önce göstermek

luckgram-skill.zip dosyasını indir SKILL.md dosyasını oku

Claude Code için kurulum:

curl -LO https://luckgram.cc/skills/luckgram/luckgram-skill.zip
unzip luckgram-skill.zip -d ~/.claude/skills/
node ~/.claude/skills/luckgram/bin/luckgram config --local --token-stdin

Son komut beklerken erişim belirtecini yapıştır, ardından Enter'a ve Ctrl-D'ye bas.
