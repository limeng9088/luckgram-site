Luckgram MCP

Luckgram Desktop'ta yerleşik bir MCP sunucusu vardır. Yapay zekâ aracın, bilgisayarındaki Telegram hesaplarını listeler, aralarında geçiş yapar ve her hesap için izin verdiğin becerileri kullanır.

  • Varsayılan olarak kapalıSunucuyu, bulutu ve her hesabın her becerisini sen açarsın.
  • Önce yerelYalnızca 127.0.0.1 adresini dinler. Bulut isteğe bağlıdır.
  • Yerleşik sınırlarHesapta değişiklik yapan her işlem, hesap başına hız sınırına tabidir.

Hızlı başlangıç

  1. Windows için Luckgram Desktop uygulamasını kur ve hesaplarına giriş yap.
  2. Settings → Luckgram → Local MCP server bölümünü aç ve etkinleştir.
  3. Satıra tıkla ve Copy client config ya da Copy access token seçeneğini kullan.
  4. Yapay zekâ aracını bağla (sonraki bölüm) ve ona şunu sor: “Hangi Telegram hesaplarına giriş yaptım?”

Yapay zekâ aracını bağla

<TOKEN>, ayarlar sayfasındaki erişim belirtecidir. Bulut için adres olarak https://mcp.luckgram.cc/mcp, belirteç olarak da bulut anahtarını kullan; gerisi aynıdır.

Claude Code

claude mcp add --transport http luckgram http://127.0.0.1:28765/mcp \
  --header "Authorization: Bearer <TOKEN>"

claude mcp list ile kontrol et: luckgram satırı Connected ile biter.

Kiro

Bunu projendeki .kiro/settings/mcp.json dosyasına, tüm projeler için ise ~/.kiro/settings/mcp.json dosyasına yaz:

{
  "mcpServers": {
    "luckgram": {
      "url": "http://127.0.0.1:28765/mcp",
      "headers": { "Authorization": "Bearer <TOKEN>" }
    }
  }
}

Ardından Kiro'dan list_accounts aracını çağırmasını iste.

Codex

Codex belirteci bir ortam değişkeninden okur; bu yüzden belirteç yapılandırma dosyasına yazılmaz:

export LUCKGRAM_MCP_TOKEN="<TOKEN>"
codex mcp add luckgram --url http://127.0.0.1:28765/mcp \
  --bearer-token-env-var LUCKGRAM_MCP_TOKEN

Windows'ta değişkeni setx LUCKGRAM_MCP_TOKEN "<TOKEN>" ile ayarla ve yeni bir terminal aç. Komut, ~/.codex/config.toml dosyasına şunu yazar:

[mcp_servers.luckgram]
url = "http://127.0.0.1:28765/mcp"
bearer_token_env_var = "LUCKGRAM_MCP_TOKEN"

opencode

opencode mcp add luckgram --url http://127.0.0.1:28765/mcp \
  --header "Authorization=Bearer <TOKEN>"

Başlık name=value biçiminde yazılır. opencode mcp list ile kontrol et: connected gösterir. Eklemenin hemen ardından hâlâ pending yazabilir; birkaç saniye sonra yeniden çalıştır.

Diğer araçlar

HTTP üzerinden çalışan her MCP istemcisi kullanılabilir. Çoğu şu JSON'u kabul eder:

{
  "mcpServers": {
    "luckgram": {
      "type": "http",
      "url": "http://127.0.0.1:28765/mcp",
      "headers": { "Authorization": "Bearer <TOKEN>" }
    }
  }
}

Claude Code 2.1, Kiro CLI 2.31, Codex CLI 0.144 ve opencode 2.0 ile, yerel adres ve bulut adresi üzerinde test edildi.

Bulut: tüm bilgisayarların tek adreste

Yerel sunucu tek bir bilgisayarda çalışır. Bulut açıkken Luckgram Desktop dışarıya, mcp.luckgram.cc adresine bağlanır; böylece yapay zekâ aracın ona her yerden ulaşır ve birden çok bilgisayar tek adresi paylaşır. Genel IP de bağlantı noktası yönlendirme de gerekmez.

  1. İlk bilgisayarda: aynı ayarlar sayfası → Connect through the cloud seçeneğini aç. Bilgisayarında bir bulut anahtarı oluşturulur.
  2. Copy cloud client config seçeneğine tıkla ve yapay zekâ aracına yapıştır: 
    {
  "mcpServers": {
    "luckgram-cloud": {
      "type": "http",
      "url": "https://mcp.luckgram.cc/mcp",
      "headers": { "Authorization": "Bearer lgc_..." }
    }
  }
}
  3. Diğer her bilgisayarda: Use the cloud key of another computer seçeneğini kullan, anahtarı yapıştır, ardından Connect through the cloud seçeneğini aç.
  • Araçlar aynıdır; her birinde bir argüman daha vardır: device. list_devices, bilgisayarlarını ve hangilerinin çevrimiçi olduğunu gösterir.
  • Beceriler yine hesap bazındadır ve her bilgisayardaki uygulamadan açılır. Hız sınırları da her bilgisayarda ayrı sayılır.
  • list_recent_calls, buluttan geçen son 200 çağrıyı gösterir: zaman, araç, bilgisayar, hesap, başarısız olup olmadığı.
  • Ağında luckgram.cc açılmıyorsa https://lg-mcp.cat158.com/mcp yedek adresini kullan. Aynı bilgisayarlarla aynı hizmettir ve Luckgram Desktop ona kendiliğinden geçer.

Doğrudan çağırma

Sunucu, MCP'yi HTTP üzerinden konuşur: her JSON-RPC iletisi için bir POST, yanıt olarak JSON. Oturum yok, akış yok. Bir araç çağrısı şöyle görünür:

POST /mcp
Authorization: Bearer <TOKEN>
Content-Type: application/json

{"jsonrpc":"2.0","id":1,"method":"tools/call",
 "params":{"name":"list_chats","arguments":{"account":"7943234085","unread_only":true}}}

Yanıtta sonuç iki kez yer alır: content içinde metin, structuredContent içinde JSON olarak. İsteneni yapamayan araç isError: true ile yanıt verir ve nedenini sade bir dille söyler.

Bulut olmadan başka bir bilgisayardan erişmek için bağlantı noktasını SSH üzerinden yönlendir:

ssh -N -L 28765:127.0.0.1:28765 user@computer-with-luckgram

Güvenlik

  • Yerel sunucu yalnızca 127.0.0.1 adresini dinler. Ağından veya internetten ona ulaşılamaz.
  • Her istek için erişim belirteci gerekir. Belirteç bilgisayarında oluşturulur, sistemin kimlik bilgisi deposunda saklanır ve istediğin zaman yeniden oluşturulabilir.
  • Web sayfalarından gelen istekler reddedilir; yani ziyaret ettiğin bir site onu tarayıcın üzerinden çağıramaz.
  • Bulut istekleri yalnızca iletir. Argümanları, sonuçları veya sohbetleri saklamaz; bulut anahtarının kendisini de saklamaz.
  • Erişim belirtecine veya bulut anahtarına sahip olan herkes, senin açtıklarını kullanabilir. Biri sızarsa yeniden oluştur: eskisi anında geçersiz olur.
  • Bir becerinin döndürdüğü içerik yapay zekâ aracına ve onun modeline gider. Mesaj okumayı yalnızca sohbetlerini onunla paylaşmaya razı olduğun hesaplarda aç.
