Luckgram / Skill market / Read messages

Read messages

Read the messages of a chat without marking it read.

Fetches the latest messages of one chat: who wrote, when, the text, what kind of attachment. The chat in the app is not touched and stays unread.

What it can do

  • Read the newest messages of a chat, up to 100 at a time
  • Go further back with before_id
  • See what each message replies to

Ask your AI tool

  • Summarize what was said in the “Project A” group today.
  • Did anyone answer my question in that chat since this morning?

Switch it on

  1. In Luckgram Desktop open Settings → Luckgram → Local MCP server.
  2. Under Skills of each account, find the account.
  3. Switch on Read messages.

Tools

ToolWhat it doesArgumentsReturnsLimit per account
get_messagesThe latest messages of a chat, newest first.account, chat (id from list_chats or a username), limit (1–100, default 20), before_idchat_name, messages: id, date, from_name, out, text, attachment, reply_to–

account is the id from list_accounts; without it the active account is used. On the cloud every tool also takes device.

From the command line

luckgram messages get 562953914961921 --account 7943234085 --limit 50
luckgram messages get @some_channel --account 7943234085 --before 4812

With the luckgram skill for agents.

Good to know

  • Attachments are named by kind (photo, file, location…); the files themselves are not downloaded.
  • What your AI tool reads goes to that tool and its model. Switch this on only for accounts whose chats you are willing to share with it.
