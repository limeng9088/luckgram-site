Skills

What an AI tool may do with each of your accounts.

A skill is a group of tools for the Luckgram MCP server. Skills are switched on per account in Luckgram Desktop (Settings → Luckgram → Local MCP server), and every one is off at first. An AI tool that calls a skill you have not switched on is refused and told which account and skill it needs.

Skill tools take an optional account (the id from list_accounts). They work on any logged-in account without switching the window; without it they use the active account.

Accounts accounts

See the accounts logged in to Luckgram Desktop and switch the active one. Always on while the MCP server is on. Always on

ToolWhat it doesArgumentsLimit per account
list_accountsList the logged-in accounts: id, name, username, phone, unread count, which one is active.none–
get_active_accountThe account the main window shows now.none–
switch_accountMake another account the active one, like clicking it in the account list.one of id, username, phone, index–

Friends friends

See an account's friends and look users up. Read only

ToolWhat it doesArgumentsLimit per account
list_friendsThe contacts of an account, with the total count.account, query, limit, offset–
find_userLook a user up by username or phone, as seen from the account.account, one of username, phone30 an hour, 100 a day

Manage friends friends_manage

Add and remove friends. Sends no messages. Changes the account · asks once when switched on

ToolWhat it doesArgumentsLimit per account
add_friendAdd a user to the account's contacts.account, one of user_id, username, phone, optional first_name, last_name5 an hour, 20 a day
remove_friendRemove a user from the account's contacts. The chat stays.account, one of user_id, username20 an hour, 50 a day

Skill file for your agent

Agents that support skills (Claude Code and others) work better with instructions: call list_accounts first, respect the limits, report what changed. Download SKILL.md and put it where your agent loads skills from. For Claude Code:

mkdir -p ~/.claude/skills/luckgram
curl -o ~/.claude/skills/luckgram/SKILL.md https://luckgram.cc/skills/luckgram/SKILL.md

Limits are counted per account and per tool, and survive a restart. They keep accounts from being restricted by Telegram and cannot be switched off.
