Luckgram / Skill market / BotFather

BotFather

Create and manage your Telegram bots through @BotFather.

Talks to @BotFather for one account, and to nobody else: makes a new bot and hands back its API token, changes a bot's name, description, about text and commands, switches group privacy, and deletes a bot. For everything else there are three general tools that send a line, press a button and read the chat. It sees only the chat with BotFather, not the account's other chats.

What it can do

  • Create a bot and get its token in one call
  • List the account's bots, get or revoke a token
  • Set the name, description, about text and the command list
  • Switch group privacy and whether the bot may be added to groups
  • Delete a bot, with the username given twice
  • Do anything else BotFather offers, step by step: send, press, read

Ask your AI tool

  • Create a bot called “My Shop” with the username my_shop_bot and save its token to a file.
  • Set the commands of @my_shop_bot: start, order, help. Write a short description for each.
  • Which bots does my work account own?

Switch it on

  1. In Luckgram Desktop open Settings → Luckgram → Local MCP server.
  2. Under Skills of each account, find the account.
  3. Switch on BotFather. Luckgram asks you to confirm, once for this account.

From the command line

luckgram bots create my_shop_bot --name "My Shop" --out ~/my_shop_bot.token --account 7943234085
luckgram bots commands my_shop_bot 'start=Start' 'order=Track an order' 'help=How it works'
luckgram bots set my_shop_bot --description "Orders and delivery status" --privacy on
luckgram botfather send /setuserpic

With the luckgram skill for agents.

Good to know

  • A bot token is a secret: whoever has it controls the bot. The tools that create a bot, get a token or revoke one return the token to your AI tool. Switch this skill on only for accounts where you want that.
  • The general tools are not a way around: sending /newbot, /deletebot or /revoke is refused, and so are buttons that delete a bot, revoke a token or transfer a bot to someone else. Those go through their own tools; a transfer is done by you in the app.
  • Only the real @BotFather is talked to: it is checked by its Telegram id, not by its name.
  • When BotFather refuses (“Sorry, this username is already taken”), the tool stops and returns its words.
