Everything you use in Telegram

Luckgram connects to the Telegram network, so the features you rely on work from the first sign-in.

Chats and groups

Cloud chats that sync across your devices, groups of up to 200,000 members, replies, reactions and polls.

Channels

Voice and video calls

Secret Chats

Device-to-device encrypted chats with self-destructing messages.

Stories, bots and mini apps

Several accounts

Open source, start to finish

The complete code for both apps is public, and every release is built from it by GitHub Actions.

Your messages stay with Telegram

Messages go to Telegram's servers, as they would from any Telegram app. Luckgram runs no message servers of its own.

No added trackers

Luckgram does not add analytics or advertising SDKs to the apps.

Follows Telegram's updates

Luckgram is built on the official open-source apps, so new Telegram features arrive with each update.

Questions

More answers in the Help Center.

Is Luckgram an official Telegram app?

No. Luckgram is an independent app built from the open-source Telegram apps for iOS and Android. It is not made by, affiliated with, or endorsed by Telegram.

Can I use my existing Telegram account?

Yes. Sign in with your phone number. Your cloud chats, contacts and channels load from Telegram as they do in any Telegram app.

Is Luckgram free?

Yes. Every feature not marked Pro is free. Luckgram Pro is an optional membership with more AI, unlimited accounts, cloud backup and no sponsored messages. Telegram Premium and Telegram Stars are Telegram's own services and are sold and managed by Telegram.

Why isn't Luckgram on the App Store or Google Play?

Luckgram is currently distributed through GitHub Releases. The Download page always links to the latest build.

How do I install Luckgram on an iPhone?

The iOS build is an unsigned IPA. Sign it with a tool such as Sideloadly or AltStore, or with your own Apple developer certificate, then install it. The install guide walks through each step.

Which Android phones are supported?

Android 6.0 or later on a 64-bit ARM phone (arm64-v8a), which covers almost every phone sold in recent years. Allow installs from your browser or file manager when asked.

Which extra features can I use?

The features page lists every feature Luckgram adds. Those marked Available work in the current version, and those marked Pro need Luckgram Pro.

How do I get help?

Start with the Help Center. If it does not answer your question, write to support@luckgram.cc.
