Luckgram MCP

Let your AI tools work with the Telegram accounts in Luckgram Desktop.

Luckgram Desktop has an MCP server built in. Turn it on, paste one piece of config into Claude Code, Cursor or any other MCP client, and the tool can see the accounts logged in on that computer, switch between them, and use the skills you allow for each account.

Local: on your own computer

  1. Install Luckgram Desktop for Windows and sign in to your accounts.
  2. Open Settings → Luckgram → Local MCP server and switch it on. It is off by default.
  3. Click the row, then Copy client config, and paste it into the MCP settings of your AI tool:
{
  "mcpServers": {
    "luckgram": {
      "type": "http",
      "url": "http://127.0.0.1:28765/mcp",
      "headers": { "Authorization": "Bearer <TOKEN>" }
    }
  }
}

In Claude Code you can add it with one command:

claude mcp add --transport http luckgram http://127.0.0.1:28765/mcp \
  --header "Authorization: Bearer <TOKEN>"

On the same page, switch on the skills you want for each account. Until you do, the tool can only list accounts and switch between them.

What it can and cannot do

  • It lists accounts, switches the active account, and runs the tools of the skills you switched on.
  • Every skill is switched on per account and is off at first. A skill that changes something asks you to confirm once when you switch it on.
  • Reading messages and sending messages are two separate skills. Without them the tool sees no message texts and sends nothing.
  • Tools that change something are rate limited per account, so a tool stuck in a loop cannot get an account restricted by Telegram.
  • While Luckgram is locked with a passcode, nothing is listed and nothing runs.

Security

  • The server listens on 127.0.0.1 only. It cannot be reached from your network or the internet.
  • Every request needs the access token. It is generated on your computer, kept in the system credential store, and you can regenerate it at any time.
  • Requests from web pages are refused, so a site you visit cannot call it through your browser.
  • Any program on your computer that has the token can use what you switched on. Keep the token private.

From another computer

The local server is not open to the network. When your AI tool runs on another machine, forward the port over SSH and connect to it as if it were local:

ssh -N -L 28765:127.0.0.1:28765 user@computer-with-luckgram

Cloud: all your computers at one address

The local server works on one computer. With Cloud MCP on, Luckgram Desktop connects out to mcp.luckgram.cc, so your AI tool can reach it from anywhere, and several computers share one address. No public IP and no port forwarding.

  1. On the first computer: Settings → Luckgram → Local MCP server → switch on Connect through the cloud. A cloud key is made on your computer.
  2. Click Copy cloud client config and paste it into your AI tool:
{
  "mcpServers": {
    "luckgram-cloud": {
      "type": "http",
      "url": "https://mcp.luckgram.cc/mcp",
      "headers": { "Authorization": "Bearer lgc_..." }
    }
  }
}
  1. On every other computer: the same page → Use the cloud key of another computer, paste the key, then switch on Connect through the cloud.
  • The tools are the same, each with one more argument, device. The tool calls list_devices first to see your computers and which are online.
  • Skills stay per account and are switched on in the app on each computer. Rate limits are counted on each computer too.
  • The cloud only passes requests on. It does not store arguments, results or chats, and it does not store the cloud key itself.
  • list_recent_calls shows the last 200 calls that went through the cloud: time, tool, computer, account, failed or not.
  • Whoever has the cloud key can use what is switched on, on every computer of that key. If it leaks, regenerate it on the same page: the old key stops working at once.
