Luckgram / MCP

Luckgram MCP

В Luckgram Desktop встроен MCP-сервер. Ваш ИИ-инструмент получает список аккаунтов Telegram на вашем компьютере, переключается между ними и использует навыки, которые вы разрешили для каждого аккаунта.

  • По умолчанию выключеноСервер, облако и каждый навык каждого аккаунта включаете вы сами.
  • Сначала локальноСлушает только 127.0.0.1. Облако — по желанию.
  • Встроенные лимитыВсё, что изменяет аккаунт, ограничено лимитом запросов на каждый аккаунт.

Быстрый старт

  1. Установите Luckgram Desktop для Windows и войдите в свои аккаунты.
  2. Откройте Settings → Luckgram → Local MCP server и включите его.
  3. Нажмите на строку и выберите Copy client config или Copy access token.
  4. Подключите ИИ-инструмент (следующий раздел) и спросите его: «В какие аккаунты Telegram я вошёл?»

Подключите ИИ-инструмент

<TOKEN> — это токен доступа со страницы настроек. Для облака укажите адрес https://mcp.luckgram.cc/mcp, а вместо токена — облачный ключ; всё остальное так же.

Claude Code

claude mcp add --transport http luckgram http://127.0.0.1:28765/mcp \
  --header "Authorization: Bearer <TOKEN>"

Проверьте командой claude mcp list: строка luckgram заканчивается на Connected.

Kiro

Добавьте это в .kiro/settings/mcp.json в проекте или в ~/.kiro/settings/mcp.json — для всех проектов:

{
  "mcpServers": {
    "luckgram": {
      "url": "http://127.0.0.1:28765/mcp",
      "headers": { "Authorization": "Bearer <TOKEN>" }
    }
  }
}

Затем попросите Kiro вызвать list_accounts.

Codex

Codex читает токен из переменной окружения, поэтому в его файл конфигурации токен не записывается:

export LUCKGRAM_MCP_TOKEN="<TOKEN>"
codex mcp add luckgram --url http://127.0.0.1:28765/mcp \
  --bearer-token-env-var LUCKGRAM_MCP_TOKEN

В Windows задайте переменную командой setx LUCKGRAM_MCP_TOKEN "<TOKEN>" и откройте новый терминал. Команда записывает в ~/.codex/config.toml следующее:

[mcp_servers.luckgram]
url = "http://127.0.0.1:28765/mcp"
bearer_token_env_var = "LUCKGRAM_MCP_TOKEN"

opencode

opencode mcp add luckgram --url http://127.0.0.1:28765/mcp \
  --header "Authorization=Bearer <TOKEN>"

Заголовок записывается как name=value. Проверьте командой opencode mcp list: она показывает connected. Сразу после добавления может стоять pending — запустите команду ещё раз через несколько секунд.

Другие инструменты

Подойдёт любой MCP-клиент, работающий по HTTP. Большинство принимает такой JSON:

{
  "mcpServers": {
    "luckgram": {
      "type": "http",
      "url": "http://127.0.0.1:28765/mcp",
      "headers": { "Authorization": "Bearer <TOKEN>" }
    }
  }
}

Проверено с Claude Code 2.1, Kiro CLI 2.31, Codex CLI 0.144 и opencode 2.0 — с локальным и облачным адресом.

Облако: все ваши компьютеры по одному адресу

Локальный сервер работает на одном компьютере. С включённым облаком Luckgram Desktop сам подключается к mcp.luckgram.cc, поэтому ИИ-инструмент достаёт до него откуда угодно, а несколько компьютеров используют один адрес. Ни публичного IP, ни проброса портов.

  1. На первом компьютере: та же страница настроек → включите Connect through the cloud. Облачный ключ создаётся на вашем компьютере.
  2. Нажмите Copy cloud client config и вставьте конфигурацию в ИИ-инструмент: 
    {
  "mcpServers": {
    "luckgram-cloud": {
      "type": "http",
      "url": "https://mcp.luckgram.cc/mcp",
      "headers": { "Authorization": "Bearer lgc_..." }
    }
  }
}
  3. На каждом следующем компьютере: Use the cloud key of another computer, вставьте ключ, затем включите Connect through the cloud.
  • Инструменты те же, у каждого один дополнительный аргумент — device. list_devices показывает ваши компьютеры и то, какие из них в сети.
  • Навыки по-прежнему задаются для каждого аккаунта и включаются в приложении на каждом компьютере. Лимиты тоже считаются на каждом компьютере отдельно.
  • list_recent_calls показывает последние 200 вызовов, прошедших через облако: время, инструмент, компьютер, аккаунт, была ли ошибка.
  • Если luckgram.cc не открывается в вашей сети, используйте резервный адрес https://lg-mcp.cat158.com/mcp. Это тот же сервис с теми же компьютерами, и Luckgram Desktop переключается на него сам.

Прямые вызовы

Сервер работает по MCP поверх HTTP: один POST на каждое сообщение JSON-RPC, ответ в JSON. Без сессий и без потоков. Вызов инструмента выглядит так:

POST /mcp
Authorization: Bearer <TOKEN>
Content-Type: application/json

{"jsonrpc":"2.0","id":1,"method":"tools/call",
 "params":{"name":"list_chats","arguments":{"account":"7943234085","unread_only":true}}}

В ответе результат приходит дважды: текстом в content и в виде JSON в structuredContent. Инструмент, который не смог выполнить запрос, отвечает isError: true и простыми словами объясняет причину.

С другого компьютера без облака пробросьте порт через SSH:

ssh -N -L 28765:127.0.0.1:28765 user@computer-with-luckgram

Безопасность

  • Локальный сервер слушает только 127.0.0.1. Он недоступен ни из вашей сети, ни из интернета.
  • Для каждого запроса нужен токен доступа. Он создаётся на вашем компьютере, хранится в системном хранилище учётных данных, и его можно в любой момент создать заново.
  • Запросы с веб-страниц отклоняются, поэтому сайт, который вы открыли, не может обратиться к серверу через ваш браузер.
  • Облако только передаёт запросы дальше. Оно не хранит аргументы, результаты и чаты и не хранит сам облачный ключ.
  • Тот, у кого есть токен доступа или облачный ключ, может пользоваться всем, что вы включили. Если один из них утёк, создайте его заново: старый сразу перестанет работать.
  • То, что возвращает навык, попадает в ваш ИИ-инструмент и его модель. Включайте чтение сообщений только для тех аккаунтов, чьими чатами вы готовы с ним делиться.

Решение проблем

Что вы видитеЧто делать
Инструмент не подключаетсяLuckgram Desktop должен быть открыт, а Local MCP server — включён. На странице показан используемый адрес: если порт 28765 занят, берётся следующий свободный.
401, «Missing or wrong access token»Токен в вашем инструменте не совпадает с текущим. Скопируйте его заново: после Regenerate access token старый перестаёт работать.
«The … skill is off for account …»Этот навык не включён для этого аккаунта. Включите его на той же странице настроек, под именем аккаунта.
«Rate limit … Try again in N seconds»Достигнут лимит этого инструмента для аккаунта. Подождите указанное время. Лимиты нельзя отключить.
«Luckgram Desktop is locked with a passcode»Разблокируйте приложение на компьютере. Пока оно заблокировано, ничего не выводится и ничего не выполняется.
Облако сообщает, что ни один компьютер не в сетиОткройте Luckgram Desktop на том компьютере и проверьте, что Connect through the cloud включено и показывает «Connected». Там, где luckgram.cc заблокирован, приложение само переключается на резервный адрес; вашему ИИ-инструменту тоже нужен резервный адрес.
