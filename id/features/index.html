Tambahkan proxy dari kode QR, tautan, atau langganan, bahkan sebelum Anda masuk

Tidak bisa terhubung ke Telegram? Tombol proxy ada di pojok kanan atas setiap layar masuk, jadi Anda bisa menambahkan proxy SOCKS5 atau MTProto sebelum mendapatkan kode. Kini ada dua cara yang lebih cepat untuk menambahkannya. Pindai kode QR proxy atau tempel tautan tg://, t.me, atau socks5://, dan proxy itu langsung masuk ke daftar Anda, tanpa perlu mengetik server dan port. Atau tempel URL langganan Clash atau mihomo untuk mengimpor semua proxy SOCKS5-nya sekaligus; segarkan dengan sekali ketuk, dan menghapus langganan itu ikut menghapus proxy yang ditambahkannya. Daftar proxy menampilkan negara keluar dan IP setiap proxy SOCKS5, dan baris Langsung di bagian atas menampilkan jalur keluar Anda sendiri tanpa proxy. Setelah masuk, Pengaturan proxy ada di bagian atas menu ⋮ di daftar obrolan.
