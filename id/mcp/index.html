Luckgram / MCP

Luckgram MCP

Luckgram Desktop memiliki server MCP bawaan. Alat AI Anda menampilkan daftar akun Telegram di komputer Anda, beralih di antaranya, dan memakai skill yang Anda izinkan untuk tiap akun.

  • Nonaktif secara defaultServer, cloud, dan setiap skill di setiap akun diaktifkan oleh Anda sendiri.
  • Lokal lebih duluHanya mendengarkan di 127.0.0.1. Cloud bersifat opsional.
  • Batas bawaanSemua yang mengubah akun dibatasi frekuensinya per akun.

Mulai cepat

  1. Instal Luckgram Desktop untuk Windows dan masuk ke akun Anda.
  2. Buka Settings → Luckgram → Local MCP server lalu aktifkan.
  3. Klik baris itu dan gunakan Copy client config atau Copy access token.
  4. Hubungkan alat AI Anda (bagian berikutnya) dan tanyakan: “Saya sedang masuk ke akun Telegram mana saja?”

Hubungkan alat AI Anda

<TOKEN> adalah token akses dari halaman pengaturan. Untuk cloud, gunakan https://mcp.luckgram.cc/mcp sebagai alamat dan kunci cloud sebagai token; selebihnya sama.

Claude Code

claude mcp add --transport http luckgram http://127.0.0.1:28765/mcp \
  --header "Authorization: Bearer <TOKEN>"

Periksa dengan claude mcp list: baris luckgram diakhiri dengan Connected.

Kiro

Letakkan ini di .kiro/settings/mcp.json dalam proyek Anda, atau di ~/.kiro/settings/mcp.json untuk semua proyek:

{
  "mcpServers": {
    "luckgram": {
      "url": "http://127.0.0.1:28765/mcp",
      "headers": { "Authorization": "Bearer <TOKEN>" }
    }
  }
}

Lalu minta Kiro memanggil list_accounts.

Codex

Codex membaca token dari variabel lingkungan, jadi token tidak ditulis ke file konfigurasinya:

export LUCKGRAM_MCP_TOKEN="<TOKEN>"
codex mcp add luckgram --url http://127.0.0.1:28765/mcp \
  --bearer-token-env-var LUCKGRAM_MCP_TOKEN

Di Windows, atur variabelnya dengan setx LUCKGRAM_MCP_TOKEN "<TOKEN>" lalu buka terminal baru. Perintah itu menulis ini ke ~/.codex/config.toml:

[mcp_servers.luckgram]
url = "http://127.0.0.1:28765/mcp"
bearer_token_env_var = "LUCKGRAM_MCP_TOKEN"

opencode

opencode mcp add luckgram --url http://127.0.0.1:28765/mcp \
  --header "Authorization=Bearer <TOKEN>"

Header ditulis sebagai name=value. Periksa dengan opencode mcp list: hasilnya menampilkan connected. Tepat setelah ditambahkan, statusnya mungkin masih pending; jalankan lagi beberapa detik kemudian.

Alat lain

Semua klien MCP yang mendukung HTTP bisa dipakai. Sebagian besar menerima JSON ini:

{
  "mcpServers": {
    "luckgram": {
      "type": "http",
      "url": "http://127.0.0.1:28765/mcp",
      "headers": { "Authorization": "Bearer <TOKEN>" }
    }
  }
}

Diuji dengan Claude Code 2.1, Kiro CLI 2.31, Codex CLI 0.144, dan opencode 2.0, pada alamat lokal dan alamat cloud.

Cloud: semua komputer Anda di satu alamat

Server lokal bekerja di satu komputer. Dengan cloud aktif, Luckgram Desktop membuat koneksi keluar ke mcp.luckgram.cc, sehingga alat AI Anda bisa menjangkaunya dari mana saja dan beberapa komputer berbagi satu alamat. Tanpa IP publik, tanpa penerusan port.

  1. Di komputer pertama: halaman pengaturan yang sama → aktifkan Connect through the cloud. Kunci cloud dibuat di komputer Anda.
  2. Klik Copy cloud client config dan tempelkan ke alat AI Anda: 
    {
  "mcpServers": {
    "luckgram-cloud": {
      "type": "http",
      "url": "https://mcp.luckgram.cc/mcp",
      "headers": { "Authorization": "Bearer lgc_..." }
    }
  }
}
  3. Di setiap komputer lain: Use the cloud key of another computer, tempelkan kuncinya, lalu aktifkan Connect through the cloud.
  • Tool-nya sama, masing-masing dengan satu argumen tambahan, device. list_devices menampilkan komputer Anda dan mana yang online.
  • Skill tetap berlaku per akun dan diaktifkan di aplikasi pada tiap komputer. Batas frekuensi juga dihitung di tiap komputer.
  • list_recent_calls menampilkan 200 panggilan terakhir yang melewati cloud: waktu, tool, komputer, akun, gagal atau tidak.
  • Jika luckgram.cc tidak bisa dibuka di jaringan Anda, gunakan alamat cadangan https://lg-mcp.cat158.com/mcp. Ini layanan yang sama dengan komputer yang sama, dan Luckgram Desktop beralih ke sana dengan sendirinya.

Memanggil langsung

Server memakai MCP lewat HTTP: satu POST per pesan JSON-RPC, jawabannya JSON. Tanpa sesi, tanpa stream. Pemanggilan tool terlihat seperti ini:

POST /mcp
Authorization: Bearer <TOKEN>
Content-Type: application/json

{"jsonrpc":"2.0","id":1,"method":"tools/call",
 "params":{"name":"list_chats","arguments":{"account":"7943234085","unread_only":true}}}

Jawaban memuat hasilnya dua kali: sebagai teks di content dan sebagai JSON di structuredContent. Tool yang tidak bisa melakukan apa yang diminta menjawab dengan isError: true dan menjelaskan alasannya dengan kata-kata sederhana.

Dari komputer lain tanpa cloud, teruskan port lewat SSH:

ssh -N -L 28765:127.0.0.1:28765 user@computer-with-luckgram

Keamanan

  • Server lokal hanya mendengarkan di 127.0.0.1. Server ini tidak bisa dijangkau dari jaringan Anda maupun dari internet.
  • Setiap permintaan memerlukan token akses. Token dibuat di komputer Anda, disimpan di penyimpanan kredensial sistem, dan bisa dibuat ulang kapan saja.
  • Permintaan dari halaman web ditolak, sehingga situs yang Anda kunjungi tidak bisa memanggilnya lewat browser Anda.
  • Cloud hanya meneruskan permintaan. Cloud tidak menyimpan argumen, hasil, atau obrolan, dan tidak menyimpan kunci cloud itu sendiri.
  • Siapa pun yang memegang token akses atau kunci cloud bisa memakai apa yang Anda aktifkan. Jika salah satunya bocor, buat ulang: yang lama langsung berhenti berfungsi.
  • Apa yang dikembalikan sebuah skill diteruskan ke alat AI Anda dan modelnya. Aktifkan pembacaan pesan hanya untuk akun yang obrolannya bersedia Anda bagikan kepadanya.

Pemecahan masalah

Yang Anda lihatYang perlu dilakukan
Alat tidak bisa terhubungLuckgram Desktop harus terbuka, dengan Local MCP server diaktifkan. Halaman itu menampilkan alamat yang dipakai: jika port 28765 sudah terpakai, port kosong berikutnya yang digunakan.
401, “Missing or wrong access token”Token di alat Anda bukan token yang berlaku saat ini. Salin lagi; setelah Regenerate access token, token lama tidak berfungsi lagi.
“The … skill is off for account …”Skill itu belum diaktifkan untuk akun tersebut. Aktifkan di halaman pengaturan yang sama, di bawah nama akun itu.
“Rate limit … Try again in N seconds”Batas per akun untuk tool itu sudah tercapai. Tunggu selama waktu yang disebutkan. Batas ini tidak bisa dimatikan.
“Luckgram Desktop is locked with a passcode”Buka kunci aplikasi di komputer. Selama terkunci, tidak ada yang ditampilkan dan tidak ada yang dijalankan.
Cloud mengatakan tidak ada komputer yang onlineBuka Luckgram Desktop di komputer itu dan pastikan Connect through the cloud aktif dan bertuliskan “Connected”. Jika luckgram.cc diblokir, aplikasi beralih sendiri ke alamat cadangan; alat AI Anda juga perlu memakai alamat cadangan.
