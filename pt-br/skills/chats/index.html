Chats

Veja a lista de chats e as contagens de não lidas. Sem o texto das mensagens.

Lê a lista de chats de uma conta na ordem dela: o tipo de chat, o nome, quantas não lidas, se está silenciado ou fixado, quando chegou a última mensagem. Nunca retorna o que as mensagens dizem.

O que ela pode fazer

  • Listar os chats, os fixados primeiro, depois pela última mensagem
  • Mostrar só os chats com mensagens não lidas
  • Fornecer o id do chat de que as ferramentas de mensagens precisam

Peça à sua ferramenta de IA

  • O que há de não lido em cada uma das minhas contas? Agrupe por conta.
  • Quais grupos da minha conta de trabalho estão parados há uma semana?

Como ativar

  1. No Luckgram Desktop, abra Settings → Luckgram → Local MCP server.
  2. Em Skills of each account, encontre a conta.
  3. Ative Chats.

Ferramentas

FerramentaO que fazArgumentosRetornoLimite por conta
list_chatsA lista de chats de uma conta.account, unread_only, limit (1–200, padrão 50), offsettotal, complete, chats: id, type, name, username, unread, muted, pinned, last_message_date–

account é o id de list_accounts; sem ele, a conta ativa é usada. Na nuvem, toda ferramenta também recebe device.

Pela linha de comando

luckgram chats list --account 7943234085 --unread
luckgram chats list --account 7943234085 --limit 100 --json

Com a skill luckgram para agentes.

Bom saber

  • Só a lista principal é retornada, não os chats arquivados.
  • complete: false significa que o app carregou até agora só o início de uma lista longa.
