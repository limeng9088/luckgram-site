Amigos

Veja os amigos de uma conta e procure pessoas.

Lê a lista de contatos de uma conta e procura um usuário por nome de usuário ou número de telefone, como essa conta o vê. Não altera nada.

O que ela pode fazer

  • Listar amigos com nome, nome de usuário e telefone, filtrados por texto
  • Encontrar um usuário por nome de usuário ou telefone e ver se ele já é amigo
  • Percorrer listas longas página por página

Peça à sua ferramenta de IA

  • Quantos amigos a minha conta de suporte tem? Mostre aqueles cujo nome contém “Li”.
  • @some_user já é amigo da minha conta de trabalho?

Como ativar

  1. No Luckgram Desktop, abra Settings → Luckgram → Local MCP server.
  2. Em Skills of each account, encontre a conta.
  3. Ative Friends.

Ferramentas

FerramentaO que fazArgumentosRetornoLimite por conta
list_friendsOs contatos de uma conta, com a contagem total.account, query, limit (1–1000, padrão 200), offsettotal, friends: id, name, username, phone, bot, mutual–
find_userProcura um usuário por nome de usuário ou telefone.account, um entre username, phoneuser: id, name, username, friend30 por hora, 100 por dia

account é o id de list_accounts; sem ele, a conta ativa é usada. Na nuvem, toda ferramenta também recebe device.

Pela linha de comando

luckgram friends list --account 7943234085 --query Li
luckgram friends find @some_user --account 7943234085

Com a skill luckgram para agentes.

Bom saber

  • Um número de telefone só é encontrado quando esse usuário permite que a conta o encontre pelo número.
  • A primeira chamada depois que o Luckgram inicia busca os contatos no Telegram e pode levar alguns segundos.
