Perfil

Altere o nome e a bio de uma conta.

Altera o nome, o sobrenome ou a bio de uma conta. O que você deixar de fora continua como está.

O que ela pode fazer

  • Alterar o nome e o sobrenome
  • Alterar ou limpar a bio

Peça à sua ferramenta de IA

  • Defina a bio da minha conta de suporte como “Seg–Sex, 9:00–18:00”.

Como ativar

  1. No Luckgram Desktop, abra Settings → Luckgram → Local MCP server.
  2. Em Skills of each account, encontre a conta.
  3. Ative Profile. O Luckgram pede que você confirme, uma vez para esta conta.

Ferramentas

FerramentaO que fazArgumentosRetornoLimite por conta
update_profileAltera o nome e / ou a bio.account, pelo menos um entre first_name, last_name, bioupdated, name, bio5 por hora, 10 por dia

account é o id de list_accounts; sem ele, a conta ativa é usada. Na nuvem, toda ferramenta também recebe device.

Pela linha de comando

luckgram profile set --bio "Mon–Fri, 9:00–18:00" --account 7943234085
luckgram profile set --first "Li" --last "" --account 7943234085
