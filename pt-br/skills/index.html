Como uma skill é ativada

  1. Ative o servidor MCPNo Luckgram Desktop: Settings → Luckgram → Local MCP server.
  2. Ative as skills por contaNa mesma página, abaixo do nome de cada conta. Uma skill que altera a conta pede que você confirme uma vez.
  3. Conecte sua ferramenta de IAClaude Code, Kiro, Codex, opencode ou qualquer cliente MCP. Veja como.

A skill luckgram para agentes

Uma ferramenta de linha de comando e instruções para agentes que carregam skills, como o Claude Code. Um só comando cobre todas as skills acima; o token de acesso é lido da entrada padrão, guardado com permissões só para o dono e nunca é exibido.

  • luckgram accounts, chats list, messages get, messages send, friends add e os demais
  • Funciona com o servidor local e com a nuvem; Node 18 ou superior, sem dependências
  • Regras para o agente: começar pela lista de contas, respeitar os limites, mostrar a mensagem antes de enviar

Baixar luckgram-skill.zip Ler SKILL.md

Instalar para o Claude Code:

curl -LO https://luckgram.cc/skills/luckgram/luckgram-skill.zip
unzip luckgram-skill.zip -d ~/.claude/skills/
node ~/.claude/skills/luckgram/bin/luckgram config --local --token-stdin

Cole o token de acesso quando o último comando ficar esperando, depois pressione Enter e Ctrl-D.
