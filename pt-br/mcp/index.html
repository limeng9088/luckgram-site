Luckgram / MCP

Luckgram MCP

O Luckgram Desktop tem um servidor MCP integrado. Sua ferramenta de IA lista as contas do Telegram no seu computador, alterna entre elas e usa as skills que você permite para cada conta.

  • Desativado por padrãoO servidor, a nuvem e cada skill de cada conta são ativados por você.
  • Local em primeiro lugarEscuta apenas em 127.0.0.1. A nuvem é opcional.
  • Limites integradosTudo o que altera uma conta tem limite de uso por conta.

Início rápido

  1. Instale o Luckgram Desktop para Windows e entre nas suas contas.
  2. Abra Settings → Luckgram → Local MCP server e ative.
  3. Clique na linha e use Copy client config ou Copy access token.
  4. Conecte sua ferramenta de IA (próxima seção) e pergunte a ela: “Em quais contas do Telegram eu estou logado?”

Conecte sua ferramenta de IA

<TOKEN> é o token de acesso da página de configurações. Para a nuvem, use https://mcp.luckgram.cc/mcp como endereço e a chave da nuvem como token; todo o resto é igual.

Claude Code

claude mcp add --transport http luckgram http://127.0.0.1:28765/mcp \
  --header "Authorization: Bearer <TOKEN>"

Verifique com claude mcp list: a linha de luckgram termina com Connected.

Kiro

Coloque isto em .kiro/settings/mcp.json no seu projeto, ou em ~/.kiro/settings/mcp.json para todos os projetos:

{
  "mcpServers": {
    "luckgram": {
      "url": "http://127.0.0.1:28765/mcp",
      "headers": { "Authorization": "Bearer <TOKEN>" }
    }
  }
}

Depois, peça ao Kiro para chamar list_accounts.

Codex

O Codex lê o token de uma variável de ambiente, então ele não fica gravado no arquivo de configuração:

export LUCKGRAM_MCP_TOKEN="<TOKEN>"
codex mcp add luckgram --url http://127.0.0.1:28765/mcp \
  --bearer-token-env-var LUCKGRAM_MCP_TOKEN

No Windows, defina a variável com setx LUCKGRAM_MCP_TOKEN "<TOKEN>" e abra um novo terminal. O comando grava isto em ~/.codex/config.toml:

[mcp_servers.luckgram]
url = "http://127.0.0.1:28765/mcp"
bearer_token_env_var = "LUCKGRAM_MCP_TOKEN"

opencode

opencode mcp add luckgram --url http://127.0.0.1:28765/mcp \
  --header "Authorization=Bearer <TOKEN>"

O cabeçalho é escrito como name=value. Verifique com opencode mcp list: ele mostra connected. Logo depois de adicionar, ainda pode aparecer pending; execute de novo alguns segundos depois.

Outras ferramentas

Qualquer cliente MCP que fale HTTP funciona. A maioria aceita este JSON:

{
  "mcpServers": {
    "luckgram": {
      "type": "http",
      "url": "http://127.0.0.1:28765/mcp",
      "headers": { "Authorization": "Bearer <TOKEN>" }
    }
  }
}

Testado com Claude Code 2.1, Kiro CLI 2.31, Codex CLI 0.144 e opencode 2.0, com o endereço local e o da nuvem.

Nuvem: todos os seus computadores em um só endereço

O servidor local funciona em um computador. Com a nuvem ativada, o Luckgram Desktop se conecta a mcp.luckgram.cc, então sua ferramenta de IA o alcança de qualquer lugar e vários computadores compartilham um endereço. Sem IP público, sem redirecionamento de portas.

  1. No primeiro computador: a mesma página de configurações → ative Connect through the cloud. Uma chave da nuvem é criada no seu computador.
  2. Clique em Copy cloud client config e cole na sua ferramenta de IA: 
    {
  "mcpServers": {
    "luckgram-cloud": {
      "type": "http",
      "url": "https://mcp.luckgram.cc/mcp",
      "headers": { "Authorization": "Bearer lgc_..." }
    }
  }
}
  3. Em cada um dos outros computadores: Use the cloud key of another computer, cole a chave e depois ative Connect through the cloud.
  • As ferramentas são as mesmas, cada uma com um argumento a mais, device. list_devices mostra seus computadores e quais estão online.
  • As skills continuam sendo por conta e são ativadas no app de cada computador. Os limites de uso também são contados em cada computador.
  • list_recent_calls mostra as últimas 200 chamadas que passaram pela nuvem: horário, ferramenta, computador, conta, se falhou ou não.
  • Se luckgram.cc não abrir na sua rede, use o endereço reserva https://lg-mcp.cat158.com/mcp. É o mesmo serviço com os mesmos computadores, e o Luckgram Desktop muda para ele sozinho.

Chamada direta

O servidor fala MCP sobre HTTP: um POST por mensagem JSON-RPC, uma resposta em JSON. Sem sessão, sem stream. Uma chamada de ferramenta é assim:

POST /mcp
Authorization: Bearer <TOKEN>
Content-Type: application/json

{"jsonrpc":"2.0","id":1,"method":"tools/call",
 "params":{"name":"list_chats","arguments":{"account":"7943234085","unread_only":true}}}

A resposta traz o resultado duas vezes: como texto em content e como JSON em structuredContent. Uma ferramenta que não conseguiu fazer o que foi pedido responde com isError: true e diz o motivo em palavras simples.

De outro computador sem a nuvem, redirecione a porta por SSH:

ssh -N -L 28765:127.0.0.1:28765 user@computer-with-luckgram

Segurança

  • O servidor local escuta apenas em 127.0.0.1. Ele não pode ser acessado da sua rede nem da internet.
  • Toda requisição precisa do token de acesso. Ele é gerado no seu computador, fica guardado no armazenamento de credenciais do sistema e pode ser gerado de novo a qualquer momento.
  • Requisições vindas de páginas web são recusadas, então um site que você visita não consegue chamá-lo pelo seu navegador.
  • A nuvem apenas repassa as requisições. Ela não armazena argumentos, resultados nem chats, e não armazena a própria chave da nuvem.
  • Quem tiver o token de acesso ou a chave da nuvem pode usar o que você ativou. Se um deles vazar, gere outro: o antigo para de funcionar na hora.
  • O que uma skill retorna vai para sua ferramenta de IA e o modelo dela. Ative a leitura de mensagens apenas nas contas cujos chats você aceita compartilhar com ela.

Solução de problemas

O que você vêO que fazer
A ferramenta não consegue conectarO Luckgram Desktop precisa estar aberto, com Local MCP server ativado. A página mostra o endereço em uso: quando a porta 28765 está ocupada, a próxima livre é usada.
401, “Missing or wrong access token”O token na sua ferramenta não é o atual. Copie-o de novo; depois de Regenerate access token, o antigo para de funcionar.
“The … skill is off for account …”Essa skill não está ativada para essa conta. Ative-a na mesma página de configurações, abaixo do nome da conta.
“Rate limit … Try again in N seconds”O limite por conta dessa ferramenta foi atingido. Aguarde o tempo indicado. Os limites não podem ser desativados.
“Luckgram Desktop is locked with a passcode”Desbloqueie o app no computador. Enquanto ele está bloqueado, nada é listado e nada é executado.
A nuvem diz que nenhum computador está onlineAbra o Luckgram Desktop nesse computador e verifique se Connect through the cloud está ativado e mostra “Connected”. Onde luckgram.cc está bloqueado, o app muda sozinho para o endereço reserva; sua ferramenta de IA também precisa do endereço reserva.

O Luckgram é um cliente independente que usa a API do Telegram. Não é um app oficial do Telegram. Use a automação dentro dos Termos de Serviço do Telegram.
