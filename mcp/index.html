Luckgram MCP

让你的 AI 工具直接操作 Luckgram 桌面版里的 Telegram 账号。

Luckgram 桌面版内置了 MCP 接口。打开开关，把一段配置粘贴到 Claude Code、Cursor 或其他支持 MCP 的工具里，它就能看到这台电脑上已登录的账号、在账号之间切换，并使用你为每个账号开启的 Skill。

本机版：在自己的电脑上用

  1. 安装 Windows 版 Luckgram 桌面版并登录账号。
  2. 打开 设置 → Luckgram 功能 → 本机 MCP 接口，把开关打开。默认是关闭的。
  3. 点进这一行，点复制客户端配置，粘贴到 AI 工具的 MCP 配置里：
{
  "mcpServers": {
    "luckgram": {
      "type": "http",
      "url": "http://127.0.0.1:28765/mcp",
      "headers": { "Authorization": "Bearer <TOKEN>" }
    }
  }
}

Claude Code 也可以用一条命令添加：

claude mcp add --transport http luckgram http://127.0.0.1:28765/mcp \
  --header "Authorization: Bearer <TOKEN>"

在同一页里，按账号开启需要的 Skill。不开启时，工具只能列出账号和切换账号。

能做什么，不能做什么

  • 列出账号、切换当前账号，以及运行你已开启的 Skill 里的工具。
  • 每个 Skill 都按账号单独开启，默认全部关闭。会改动账号的 Skill 在开启时要你确认一次。
  • 读不到消息内容，也不能发消息。
  • 会改动账号的工具按账号限制频率，避免工具陷入循环导致账号被 Telegram 限制。
  • Luckgram 被本地密码锁住时，不列出任何账号，也不执行任何操作。

安全

  • 只监听 127.0.0.1，局域网和外网都连不上。
  • 每个请求都要带访问令牌。令牌在你的电脑上生成，保存在系统凭据库里，随时可以重新生成。
  • 来自网页的请求会被拒绝，你访问的网站无法借浏览器调用它。
  • 拿到令牌的本机程序都能使用你已开启的功能，请不要把令牌发给别人。

从另一台电脑调用

本机接口不对外开放。AI 工具运行在别的机器上时，用 SSH 把端口转发过去，再像本机一样连接：

ssh -N -L 28765:127.0.0.1:28765 user@computer-with-luckgram

云端版：一个地址管理所有电脑开发中

云端 MCP 还没有上线，计划是这样的：

  • 在桌面版里登录 Luckgram 账号并打开云端 MCP。应用主动连到 Luckgram，不需要公网地址和端口转发。
  • AI 工具只用连一个地址，用 Luckgram 账号授权。工具可以指定设备和账号，一个 Agent 就能操作你接入的所有电脑。
  • Skill 仍然按账号开启，在每台电脑的应用里设置。云端只转发请求并记录调用日志，不保存聊天内容。

Luckgram 是使用 Telegram API 的第三方客户端，不是 Telegram 官方应用。请在 Telegram 服务条款允许的范围内使用自动化功能。
