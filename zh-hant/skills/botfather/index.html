BotFather 機器人管理

透過 @BotFather 建立和管理你的 Telegram 機器人。

以某個帳號的身分和 @BotFather 對話，而且只和它對話：建立新機器人並取回 API 權杖，修改機器人的名稱、說明、簡介和指令，切換群組隱私模式，刪除機器人。其餘的事情有三個通用工具：傳一句話、點一個按鈕、讀這個聊天。它只能看到和 BotFather 的聊天，看不到帳號的其他聊天。

能做什麼

  • 一次呼叫就建立機器人並拿到權杖
  • 列出帳號的機器人，取得權杖或重設權杖
  • 設定名稱、說明、簡介和指令列表
  • 切換群組隱私模式、是否允許被加進群組
  • 刪除機器人，需要把使用者名稱寫兩次
  • BotFather 的其他功能也能一步一步完成：傳送、點按鈕、讀取

對 AI 工具這樣說

  • 建立一個叫「我的小店」的機器人，使用者名稱 my_shop_bot，把權杖儲存到檔案裡。
  • 為 @my_shop_bot 設定指令：start、order、help，每個配一句簡短說明。
  • 我的工作帳號名下有哪些機器人？

怎麼開啟

  1. 在 Luckgram 桌面版裡開啟 設定 → Luckgram 功能 → 本機 MCP 伺服器。
  2. 在每個帳號的 Skill 下面找到那個帳號。
  3. 開啟BotFather。 Luckgram 會請你確認一次，每個帳號只確認一次。

命令列

luckgram bots create my_shop_bot --name "My Shop" --out ~/my_shop_bot.token --account 7943234085
luckgram bots commands my_shop_bot 'start=Start' 'order=Track an order' 'help=How it works'
luckgram bots set my_shop_bot --description "Orders and delivery status" --privacy on
luckgram botfather send /setuserpic

需要安裝給 Agent 用的 luckgram Skill。

注意事項

  • 機器人權杖是機密，拿到它的人就能控制機器人。建立機器人、取得權杖、重設權杖這三個工具會把權杖回傳給你的 AI 工具。只為你願意這樣做的帳號開啟。
  • 通用工具不是後門：傳送 /newbot、/deletebot、/revoke 會被拒絕，刪除機器人、重設權杖、把機器人轉移給別人的按鈕也會被拒絕。這些操作只能走各自的工具；轉移只能由你在應用程式裡完成。
  • 只和真正的 @BotFather 對話：依它的 Telegram id 核對，而不是依名字。
  • BotFather 拒絕時（例如「這個使用者名稱已被使用」），工具會立即停下並原樣回傳它的話。
