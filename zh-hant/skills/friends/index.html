好友

查看帳號的好友，依使用者名稱或手機號碼尋找使用者。

讀取某個帳號的好友列表，並以該帳號的身分依使用者名稱或手機號碼尋找使用者。它不會變更任何東西。

能做什麼

  • 列出好友的名稱、使用者名稱、手機號碼，可依文字篩選
  • 依使用者名稱或手機號碼尋找使用者，並得知是否已經是好友
  • 對很長的列表分頁讀取

對 AI 工具這樣說

  • 我的客服帳號有多少好友？把名字裡帶「李」的列出來。
  • @some_user 是不是我工作帳號的好友？

怎麼開啟

  1. 在 Luckgram 桌面版裡開啟 設定 → Luckgram 功能 → 本機 MCP 伺服器。
  2. 在每個帳號的 Skill 下面找到那個帳號。
  3. 開啟好友。

工具

工具作用參數回傳每個帳號的上限
list_friends帳號的好友列表和總數。account、query、limit（1–1000，預設 200）、offsettotal、friends：id、name、username、phone、bot、mutual–
find_user依使用者名稱或手機號碼尋找使用者。account，username、phone 二選一user：id、name、username、friend每小時 30 次，每天 100 次

account 是 list_accounts 回傳的 id，不填就是目前帳號。在雲端，每個工具還可以帶 device。

命令列

luckgram friends list --account 7943234085 --query Li
luckgram friends find @some_user --account 7943234085

需要安裝給 Agent 用的 luckgram Skill。

注意事項

  • 只有對方允許透過手機號碼找到自己時，依手機號碼才查得到。
  • Luckgram 啟動後的第一次呼叫要向 Telegram 取得通訊錄，可能需要幾秒。

搭配使用
