管理聊天

把聊天標記為已讀。

把某個帳號的一個聊天裡的訊息全部標記為已讀，效果和開啟這個聊天一樣。它和讀訊息是分開的，所以 AI 工具可以讀完一個聊天而保持未讀狀態。

能做什麼

  • 把一個聊天標記為已讀，並回傳之前有多少則未讀

對 AI 工具這樣說

  • 摘要我看過了，把那三個聊天標記為已讀。

怎麼開啟

  1. 在 Luckgram 桌面版裡開啟 設定 → Luckgram 功能 → 本機 MCP 伺服器。
  2. 在每個帳號的 Skill 下面找到那個帳號。
  3. 開啟管理聊天。 Luckgram 會請你確認一次，每個帳號只確認一次。

工具

工具作用參數回傳每個帳號的上限
mark_chat_read把一個聊天裡的訊息全部標記為已讀。account、chatchat_id、chat_name、was_unread每小時 60 次，每天 500 次

account 是 list_accounts 回傳的 id，不填就是目前帳號。在雲端，每個工具還可以帶 device。

命令列

luckgram chats read 562953914961921 --account 7943234085

需要安裝給 Agent 用的 luckgram Skill。

注意事項

  • 對方會看到訊息已讀，和你自己開啟聊天一樣。

搭配使用

聊天查看聊天列表和未讀數，不含訊息內容。唯讀讀訊息讀取聊天裡的訊息，不會標記已讀。唯讀
